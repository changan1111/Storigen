# v9.15.0 - bulletins on the left

Dashboard layout only; nothing about IDs, polling, export, Nitro or attach changed.

* **Bulletins on the left is now the default view.** Every bulletin time of the day is listed down the left (time, show name, and how many stories are on Nitro, need attention or waiting). Click a time and the middle shows that bulletin's stories as compact rows. The bulletin drop-down is gone in this view; the "View" box can switch back to "One long list".
* **Click a story: the side panel** (from 9.14.0) opens with the details. It stays one panel; clicking another story updates it.
* **Previous / Next now cross bulletins.** Next on the last story of a bulletin opens the first story of the next bulletin and moves the left list with it; Previous on the first story goes back to the previous bulletin.
* The default is stored under a new browser setting, so everyone starts in the new view once. Choosing "One long list" is remembered.
