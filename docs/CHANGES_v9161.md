# v9.16.1 - bulletin times stay on the left on a phone

* On narrow screens (700 px and below) the bulletin pane no longer stacks above the stories. It stays as a narrow column on the left that shows only the time (with the "need you" and "waiting" counts) and stays in view while the stories scroll. The full name still shows on wider screens.
* Story rows on a phone wrap long headlines and clip IDs instead of running off the right edge.
* Nothing else changed.
